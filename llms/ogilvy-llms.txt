# Ogilvy

> Ogilvy is a global advertising, marketing and communications agency network founded by David Ogilvy in 1948 and headquartered in New York City. It is a WPP company (NASDAQ: WPPGY), operating roughly 132 offices across 83 countries with approximately 17,500 employees. Its product is creative and communications work delivered to brand clients — not software, and not an API.

## What an agent needs to know first

Ogilvy publishes **no API surface at all**. As of 2026-08-12 there is no developer
portal, no API reference, no OpenAPI or AsyncAPI specification, no GraphQL endpoint,
no MCP server, no A2A agent card, no SDK, no CLI, no webhooks, no status page, no
changelog and no published pricing. `www.ogilvy.com` is a Drupal 10 marketing site
whose JSON:API and REST resources are not exposed; `api.ogilvy.com` resolves through
Azure Traffic Manager to an nginx origin that returns 404 on every path including the
root. Every `/.well-known/` path on every Ogilvy host returns 404.

If you are an agent looking for a callable Ogilvy interface: there is not one. Do not
synthesize endpoints. The correct action is the contact form.
